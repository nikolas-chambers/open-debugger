Repositories

open-debugger

Host binaries (odbg, odbg_cli), CMake build, and plugin submodules.

github.com/nikolas-chambers/open-debugger

open-debugger-plugins_sdk

Public plugin SDK headers + sample plugin. Link against this to build a plugin.

github.com/nikolas-chambers/open-debugger-plugins_sdk

open-debugger-plugins

Public plugins (e.g. osd_dbg). Built against the SDK in-tree or standalone.

github.com/nikolas-chambers/open-debugger-plugins

open-debugger-plugins-private

Private/experimental plugins. Skipped by default in public CI; clone separately if you have access.

github.com/nikolas-chambers/open-debugger-plugins-private

Build

git clone --recursive https://github.com/nikolas-chambers/open-debugger.git
cd open-debugger
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release

Private plugins auto-skip when the submodule is unregistered. Artifacts land in build/Release/.

Plugin authors

Plugins are separate repos checked out as submodules. To build a plugin standalone against a local host:

git clone https://github.com/nikolas-chambers/open-debugger-plugins_sdk.git sdk
git clone https://github.com/nikolas-chambers/open-debugger-plugins.git myplugin
cd myplugin
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DODBG_ROOT=..\..\open-debugger
cmake --build build --config Release

CI matrix

Every repo builds Debug Release × Win32 x64 on every push/PR. Tag v* to publish release artifacts.
